# Codex 0.153.4 and GPT-6 Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development or superpowers:executing-plans to
> implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Upgrade code-mod's backend-facing Codex compatibility to 0.153.4 and
add complete `gpt-6-astra` support without regressing fork-owned behavior.

**Architecture:** Keep `code-rs` as the fork-owned backend implementation and
use OpenAI Codex `rust-v0.153.4` as the behavioral reference. Refresh the
read-only model catalog, extend reasoning with `ultra`, and carry GPT-6 through
version negotiation, model presets, family derivation, app-server conversion,
and request serialization.

**Tech Stack:** Rust, Serde, Schemars, ts-rs, Cargo workspace tests, and the
repository `build-fast.sh` verifier.

---

## File Map

- `codex-rs/models-manager/models.json`: upstream model metadata.
- `code-rs/code-version/default_version.rs`: embedded client version.
- `code-rs/code-version/src/lib.rs`: minimum-version parsing and tests.
- `code-rs/protocol/src/openai_models.rs`: serialized reasoning types.
- `code-rs/core/src/config_types.rs`: backend reasoning configuration.
- `code-rs/core/src/config.rs`: ordered accepted reasoning levels.
- `code-rs/app-server/src/message_processor/v2.rs`: protocol conversion.
- `code-rs/common/src/model_presets.rs`: fallback picker presets.
- `code-rs/core/src/model_family.rs`: model capability derivation.

## Risks and Mitigations

- **Catalog schema drift:** Parse the exact catalog in focused tests.
- **Enum exhaustiveness:** Use compiler errors plus repository-wide search.
- **Dirty worktree overlap:** Patch narrow hunks and inspect every diff.
- **Fork regressions:** Retain and test the custom GPT-5.6 presets.
- **Build pressure:** Set `CARGO_BUILD_JOBS=1` for every compile command.
